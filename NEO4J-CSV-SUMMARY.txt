USAGE INSTRUCTIONS:
================================================================================

OPTION 1: Python Script (Recommended)
--------------------------------------
python3 import_to_neo4j.py --uri bolt://localhost:7687 \
                            --user neo4j \
                            --password your_password \
                            --clear

OPTION 2: Manual CSV Import via Neo4j Browser
----------------------------------------------
1. Copy CSV files to Neo4j import directory
2. Open Neo4j Browser (http://localhost:7474)
3. Run commands from NEO4J-IMPORT-GUIDE.md

OPTION 3: Direct Cypher Queries
--------------------------------
See neo4j-examples.cypher for sample queries and data population

VERIFICATION:
================================================================================

After import, run these queries to verify:

1. Count labels by category:
   MATCH (n:SchemaLabel)
   RETURN n.category, count(*) as count
   ORDER BY count DESC;

2. Check hierarchy:
   MATCH (child:SchemaLabel)-[:SUBCLASS_OF]->(parent:SchemaLabel)
   RETURN child.name, parent.name;

3. List all relationships:
   MATCH (r:SchemaRelationship)
   RETURN r.name, r.sourceLabel, r.targetLabel;
